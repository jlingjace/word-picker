# 口语抽词器 · Taboo

团队英语口语练习游戏：抽一个英文词，用英语描述它让同事猜，但不能说出这个词本身。

**设计目标是让每个人都能完成回合。**英文好的同事自己组织语言；实在描述不出来的同事点一下「看提示」，里面是两句写好的完整英文描述和一句极简定义，**照着念就能让别人猜**。提示默认收起，每抽一个新词都要重新点开，所以能自己说的人不会被剧透。

## 怎么玩

直接用浏览器打开 `index.html`（或访问 GitHub Pages 地址）。

- 顶部按**主题 / 难度**筛选牌堆（A2 入门 / B1 进阶 / B2 挑战）
- `空格` 抽词；抽过的词在重置前不会重复
- 卡住了就点「🙋 描述不出来？点这里看提示，照着念就行」
- 「显示中文」可随时开关（默认关，避免直接照着中文翻译）

## 词库自动更新机制

页面打开时会静默拉取本仓库 `main` 分支的 `words.json`：

1. 有新版本且还没开始抽词 → 直接生效
2. 有新版本但正在玩 → 暂存，点「重置牌堆」后生效
3. 离线 → 回退到 localStorage 缓存或文件内嵌词库

所以**改 `words.json` 并 push，就等于给所有人更新了词库**。

## 加词 / 改词

1. 编辑 `words.json`，往 `words` 数组里加词条（格式见下）
2. 把顶部 `version` 改成当天日期（页面靠它判断新旧）
3. 运行 `node build.js`（校验 + 把新词库内嵌回 `index.html` 作离线兜底）
4. commit + push

### 词条格式

```json
{
  "en": "stapler",
  "zh": "订书机",
  "theme": "objects",
  "level": "B1",
  "pos": "noun",
  "sentences": [
    "You press it down to join a few pages together.",
    "Most people keep one on their desk in the office."
  ],
  "def": "a small tool that joins pages with tiny metal pins"
}
```

字段约定：

| 字段 | 说明 |
|---|---|
| `theme` | 必须是 `words.json` 顶部 `themes` 里声明过的 key |
| `level` | `A2`（简单具体）/ `B1`（进阶）/ `B2`（抽象有难度） |
| `sentences` | **2 句完整的、可以直接朗读的英文描述**。不留空、不含占位符，每句约 8–16 词、简单现在时、基础词汇；两句给不同角度（一句「是什么/做什么」，一句「典型场景或例子」），合起来足以让人猜出来 |
| `def` | 一句极简英文定义，≤14 词，只用最基础的词汇，同样要能直接朗读 |

**最重要的一条规则**：`sentences` 和 `def` 里**绝不能出现目标词或它的任何同根变形**（比如 `baker` 不能出现 bake / baking / bakery）——因为这些内容是要被念出来的，漏了词这一轮就废了。`build.js` 会自动拦下这类错误。

## 每周自动补词

一个每周执行的定时任务会自动生成一批新词（带完整句子和定义、查重、审核），更新 `words.json` 并 push。同事打开页面即可看到「已联网更新」。
